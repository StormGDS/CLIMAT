# NUCLEO: рабочий режим с реле, 28.10.2026

По подтверждению пользователя реле/нагрузки подключены, включающий уровень — **HIGH**. Рабочая F767 собрана, загружена и проверена программатором. Итоговая проверка — **PASS**. Плата оставлена в AUTO, физические выходы разрешены, PHONE TEST OFF, STREAM OFF. COM3 освобождён. Настройки Flash не менялись.

## Физическое управление

| Маска | Назначение | Вывод | ON / OFF |
|---|---|---|---|
| bit0 | K1, нагреватель 1 | PF14 / D4 | HIGH / LOW |
| bit1 | K2, нагреватель 2 | PF13 / D7 | HIGH / LOW |
| bit2 | K3, вентилятор 1 | PE9 / D6 | HIGH / LOW |
| bit3 | K4, вентилятор 2 | PE11 / D5 | HIGH / LOW |

HAL/регистры находятся только в адаптере F767. Общая логика получает необязательный callback выходов; без него плата остаётся LOCKED. Адаптер F030 callback не устанавливает и сохраняет блокировку до согласования платы.

В callback поступает только итоговая маска арбитра. Перед включением новых реле выключаются все уходящие реле на обоих GPIO-портах. При старте GPIO LOW, до первого завершённого измерения все выходы выключены. Сохраняются минимальные ON/OFF 30 с для нагревателей и 60 с для вентиляторов, взаимная блокировка, тайм-аут MANUAL, ограничения AUTO. Авария обоих датчиков/устаревших измерений задаёт K1/K2 OFF, K3 ON, K4 OFF с приоритетом над временными ограничениями. SELFTEST использует локальные модели и не переключает реальные нагрузки.

По умолчанию непрерывный вывод USART3 выключен. Консоль остаётся доступной по запросу; USART6 обслуживает штатный бинарный обмен Bluetooth.

## Протокол для приложения

Версия v1, длины кадров и opcode не менялись:

- HELLO capabilities = **6**: physical_locked=0, Flash и трёхбайтовое имя поддерживаются. У заблокированной F030 значение остаётся 7.
- В STATUS сброшен bit2 physical_locked; physical_mask содержит прочитанный GPIO ODR для K1..K4. Это состояние выходных регистров, не обратная связь контактов реле.
- В ответах MODE/RELAY physical_locked=0. Принятие запроса по-прежнему не отменяет задержек/защит арбитра.
- В `tests/phone_vectors.json` добавлен `hello_enabled_reply`; эталон заблокированной платы сохранён. Приложению нужно читать флаг из устройства, не фиксировать его равным 1.

Актуальное описание — `PHONE_PROTOCOL_V1.md`. Прежний архив передачи Android оставлен историческим снимком; эти файлы можно передать разработчику приложения как обновление.

## Проверки на подключённой плате

- F767 Release: сборка без ошибок и предупреждений компиляции; `Download verified successfully`.
- Все 7 C selftests прошли после загрузки и в финальном прогоне.
- HELLO побайтово совпал с новым эталоном разблокированной платы. STATUS: маска GPIO совпадает с логической, physical_locked=0. Прямой запрос нагревателя в AUTO отклонён с корректным physical_locked=0; нагрузки для этой проверки не включались.
- В AUTO исправен S1 `28B221F545240B6C`, errors=0; S2 отсутствует. При наблюдавшихся 24–24,25 °C запрос арбитра 0, выходы 0. Непрерывный вывод и тестовая инъекция кадров выключены.
- SWD HOTPLUG подтвердил уровни входного регистра: GPIOF IDR=`0x00009FB4`, GPIOE IDR=`0x0000F5FB`; PF14/PF13/PE9/PE11 LOW. ODR: GPIOF=`0x00008000` (отпущенная 1-Wire PF15), GPIOE=`0x00000000` — все четыре реле OFF, как требует арбитр при этой температуре. Программное управление разрешено, постоянного включения реле нет.
- Запись настроек 48 байт до/после совпала. SHA256 обеих копий: `B8DCD0A6AAAF1448961A4E87C8956C67948E6CA462F366DA76A9DD2874B14F74`. CONFIG STORAGE: VALID, ram_matches=1.
- После отладочного чтения MCU продолжает считать время и измерять температуру, неожиданный reset не обнаружен.

Телефон был подключён к BLE, что подтвердил пользователь. Поэтому AT при запуске не получил ответа: `BT BOOT state=NO_AT_RESPONSE`. Начальная проверка, требовавшая только READY, остановилась на этом условии; последующая проверка учла действующее соединение. После отключения тестового транспорта MCU принял **74 валидных запроса реального USART6**, rejected=0. Финальный сценарий `verify-f767-live-final.ps1` завершился PASS; соединение телефона не разрывалось. Отсутствие AT-ответа здесь не означает отсутствие модуля и не блокирует AUTO.

Принудительное включение каждого подключённого нагревателя/вентилятора и проверка контактов реле не выполнялись. Корректность команд/арбитра проверена C-тестами, разрешённое управление и фактические LOW — на плате. При достижении порогов реле управляются алгоритмом; при MANUAL команды проходят тот же арбитр.
