# Настройки Flash v5 — 31.10.2026

Текущий контракт: 72 байта, little-endian. Предыдущее описание сохранено
в docs/history/STAGE4_FLASH_before_2026-10-30.md.

| Offset | Размер | Поле |
|---:|---:|---|
| 0 | 4 | CLMT — commit, записывается последним |
| 4 | 2 | version=5 |
| 6 | 2 | length=72 |
| 8 | 16 | 8 × i16: h1on,h1hyst,h2on,h2hyst,c1on,c1hyst,c2on,c2hyst, 1/16 °C |
| 24 | 2 | u16: скорость остывания K2, 0,001 °C/мин; 0 отключено |
| 26 | 1 | FAIL_COUNT |
| 27 | 1 | RECOVER_COUNT |
| 28 | 1 | alternate 0/1 |
| 29 | 3 | device_name |
| 32 | 2 | MANUAL_TIMEOUT 1..3600 с |
| 34 | 2 | окно производной, фиксировано 5 с |
| 36 | 2 | нижняя граница настройки h2on, 168 = 10,5 °C |
| 38 | 2 | MIN_ON нагревателей, 1..600 с |
| 40 | 2 | MIN_ON вентиляторов, 1..600 с |
| 42 | 8 | ROM S1, Dallas byte order, 8 нулей = не назначен |
| 50 | 8 | ROM S2, аналогично |
| 58 | 2 | R роста, u16, 0,001 °C/мин, 0 отключено |
| 60 | 2 | Hrate общий, u16, 0,001 °C/мин |
| 62 | 6 | reserved=0 |
| 68 | 4 | CRC32 байтов 0..67 |

CRC-32/ISO-HDLC: poly=0x04C11DB7 (reflected 0xEDB88320), init/xorout=0xFFFFFFFF,
refin/refout=true; 123456789 → 0xCBF43926. Проверяются magic, version, length,
CRC, фиксированные политики, reserved, диапазоны/гистерезис и уникальные ROM с CRC8.

Настройки в RAM применяются без записи. SAVE проверяет запись чтением и CRC;
при совпадении байтов — UNCHANGED без стирания. LOAD при ошибке не меняет RAM.
DEFAULT очищает ROM и имя и возвращает профиль SPEC в RAM. Включение реле и MANUAL
не сохраняются. UART при реальной операции Flash временно приостанавливается.

Миграция: читать 72 байта из прежней области, но у v1-v3 проверять прежние length=48
и CRC по первым 44 байтам. Старый target проверяется как часть валидности старого
контракта и отбрасывается; H нагревателя=off-on, H вентилятора=on-off. Сохраняются
пороги, тайм-аут, alternate, fail/recover, имя v3. Для v1/v2 имя пустое. S=0,
ROM S1/S2 пустые, поскольку старые версии их не хранили. Автоматического назначения
ролей и автоматической перезаписи нет: назначить роли явно и выполнить SAVE.
Неизвестные версии/повреждённые записи не мигрировать. До SAVE после миграции
ram_matches=0. Один сектор/страница, без резервной копии; риск утраты при SAVE принят.

F030: CONFIG 0x08003C00..0x08003FFF. F767: CONFIG 0x08010000..0x0801FFFF,
сектор 2 single-bank или 4 dual-bank; перенос банков не поддерживается автоматически.
Область CONFIG не входит в загрузочный образ. Обновление firmware не должно стирать её.

Миграция v4: length=64, CRC по 0..59, прежние фиксированные 38=30,40=60,
reserved58=0 обязательны. Байты после 64 игнорируются. Сохраняются S, Ton/H,
имя, ROM, fail/recover, alternate и timeout. Новые R=Hrate=0, MIN_ON=30/60;
те же добавления применяются для v1-v3. Никаких автоматических записей.
MIN_OFF не хранится как редактируемое поле: 30/60 с в коде и GET_CONFIG.
Hrate<=R при R>0; Hrate<=S при S>0; все новые поля проверяются до применения.
F767 инвалидирует 96 байт DCache (72 округлены до 32); расположение CONFIG прежнее.
