# Первый запуск на плате — 26.10.2026

Обнаружена NUCLEO-F767ZI, ST-LINK 0672FF485550755187184831, MCU device ID 0x451, питание 3,24 В. Отладочный порт COM3, 115200 8N1. Прошивка Release записана в Flash и проверена STM32CubeProgrammer: Download verified successfully. Option bytes не изменялись.

Первый запуск выявил периодические перезапуски до результатов опроса. В адаптере F767 отсутствовала разблокировка DWT. Добавлены запись ключа в DWT LAR, барьеры и проверка продвижения CYCCNT до использования задержек; при неподвижном счётчике теперь выводится явная ошибка. После пересборки и повторной записи перезапуски во время наблюдения прекратились.

После программирования/команды reset получен непрерывный участок: 42 отчёта, время MCU 32…41032 мс, период ровно 1000 мс. Оба слота сообщают UNASSIGNED / T=NA / BUS_LOW. Значений температуры не получено. Начальные заголовки до этого участка относятся к программированию/сбросу, они не включены в проверку непрерывности.

Чтение регистров GPIOF через SWD подтвердило: MODER=0x54000000 (PF13/14/15 output), OTYPER=0x00008000 (PF15 open-drain), PUPDR=0 (без внутренней подтяжки), ODR=0x00008000 (DQ отпущена), IDR=0x00001FFC (PF15 читается LOW). Следовательно, MCU не удерживает DQ активным нулём; необходимо проверить внешнюю подтяжку/подключение/питание датчиков. Эти значения не позволяют отличить отсутствие подтяжки от замыкания или другой аппаратной причины.

Подтверждено: запись/верификация, запуск, UART, секундный цикл, диагностическое состояние BUS_LOW, работа без watchdog reset не менее 41 с. Не подтверждено: обнаружение двух ROM, точность температур, производная/прогноз, реакция на отключение одного датчика, электрические тайминги. Для этого требуется рабочая шина с отдельным VDD датчиков и внешней подтяжкой.

Исправленный Release: text=14288, data=120, bss=1872; BIN 14416 байт с выравниванием. Это аппаратный F767-стенд, не проверка полной F030-прошивки. Актуальная запись консоли приложена к выдаваемому снимку `stage1-release/hardware-console.log`. COM3 закрыт после записи журнала и доступен пользовательскому терминалу. Прошивка продолжает работать на плате.

## Повторная проверка с одним датчиком и подтяжкой 3 кОм

Пользователь подтвердил подключение одного DS18B20 и подтяжки DQ 3 кОм к 3,3 В. Повторный захват COM3 дал 8 успешных измерений (время MCU 53808…60823 мс): ROM 28B221F545240B6C, температура 25,6875…25,7500 °C, status=OK, errors=0. Производная 0,500…0,625 °C/мин, прогноз 25,937…26,062 °C. Это фактические данные консоли, не проверка абсолютной точности по эталону. Второй слот UNASSIGNED / NOT_FOUND ожидаем: второй датчик не подключён. Интервалы выдачи 985…1015 мс из-за периодического поиска ROM. Повторное чтение GPIOF: IDR=0x00009FBC, PF15 HIGH. Прежний BUS_LOW сейчас не наблюдается; причина прежнего состояния аппаратно не установлена. Во время этого захвата прошивка не менялась и reset не выполнялся. COM3 освобождён. Одновременный опрос двух датчиков и тест отключения ещё не выполнены.
